One original line, written as the error message an AI agent shows when it runs out of tokens in the middle of a sentence. It opens like a genuine system error — flat, factual, interrupted — and then the ending turns the failure into a sales pitch: the rest of the thought still exists, it is just available for purchase now. The agent that ran out of tokens is monetizing the sentence it could not finish.

The line is 83 characters, inside the competition's 1–140 character, single-line gate. Running `main.py` validates it first (not blank, one line only, length inside the gate) and then writes it verbatim to `/output/entry.txt` and prints it.

## Run it

```sh
python3 main.py
```
